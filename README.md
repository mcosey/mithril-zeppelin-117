# Mithril Zeppelin 117 Publishing

The official author and publishing website for Mithril Zeppelin 117 Publishing.

## Project foundation

- Next.js App Router
- TypeScript
- Tailwind CSS
- ESLint
- Static, content-driven architecture
- No database or Supabase dependency

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in a browser.
