# Blog posts

Each published blog post is a Markdown file in `content/posts`.

To add a post:

1. Copy `content/post-template.md.example` into `content/posts`.
2. Rename the copy with a short URL-friendly name ending in `.md`.
3. Fill in the details above the second `---` line.
4. Write the post below the second `---` line.
5. Save the file and review it locally at `/blog`.

The image and imageAlt fields are optional. Images stored in `public/images/blog` use a path such as `/images/blog/example.jpg`.
